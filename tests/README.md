# Banco de escenas

Inputs del jugador. No hay JSON. No pasan ni fallan: se leen.

```bash
python3 tests/run.py
python3 tests/run.py 18_mascota
```

Cada corrida deja en `tests/logs/` un `.journal.txt` (input, tools, prosa) y un `.sqlite`.
